# Calculadora de IMC

Aplicação desktop desenvolvida em **Java** com **Java Swing** para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário.

Este projeto faz parte dos meus estudos e da minha evolução em programação.

## ✨ Funcionalidades

- Entrada de peso e altura.
- Cálculo do IMC.
- Exibição de uma classificação de acordo com o resultado.

## 🛠️ Tecnologias

- Java
- Java Swing
- Apache Ant / projeto NetBeans

## ▶️ Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/lucaszzera/programming.git
   ```

2. Abra o projeto no NetBeans, selecionando a pasta clonada.
3. Aguarde o IDE carregar a configuração do projeto.
4. Execute a classe principal `calculadoraa.Calculadora`.

Também é possível compilar o projeto com Apache Ant, caso o ambiente esteja configurado:

```bash
ant
```
